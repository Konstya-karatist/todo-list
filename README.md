# КАДР — список задач

Простой список задач: можно запланировать задачу, отметить её выполненной или удалить. Задачи сохраняются в браузере и остаются после обновления страницы.

**Посмотреть сайт:** https://konstya-karatist.github.io/todo-list/

## Как запустить локально

Скачайте архив, распакуйте и откройте `index.html` в браузере.

## Как делал

Использовал HTML, CSS и JavaScript без фреймворков. Для хранения задач — `localStorage`.

При разработке сайта исользовал ChatGPT: с ним прорабатывал интерфейс и код, затем вносил правки по результатам проверки.
